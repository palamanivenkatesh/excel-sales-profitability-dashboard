# Sales Performance & Profitability Analysis — Excel Dashboard

## Project Overview

This project is an Excel-based sales performance and profitability analysis dashboard created to analyze business sales data and generate meaningful insights.

## Tools & Skills Used

* Microsoft Excel
* Excel Tables
* XLOOKUP
* VLOOKUP
* INDEX-MATCH
* SUMIFS / COUNTIFS
* IF / IFS
* IFERROR
* PivotTables
* PivotCharts
* Conditional Formatting
* Calculated Columns
* Data Cleaning
* Data Analysis
* Dashboard Development

## Key Analysis

The dashboard analyzes:

* Sales performance
* Profit and profitability
* Orders
* Quantity
* Region performance
* Product performance
* Employee performance

## Project Work

* Cleaned and prepared sales data for analysis.
* Used lookup and conditional formulas to connect and analyze data.
* Created calculated columns for sales, cost, profit, and profitability.
* Built PivotTables and PivotCharts for business analysis.
* Created an interactive Excel dashboard.
* Generated business insights from sales and profitability data.

## Key Business Insights

The analysis provides insights into sales performance, profitability, regional performance, product performance, and employee performance to support business decision-making.
